This version mixes multiple choice, typing, meaning questions and corrections. It also practices pronoun placement with infinitives, gerunds and affirmative/negative commands.

Object pronouns

  • Direct: lo, la, los, las
  • Indirect: me, te, le, nos, les
  • Double: se lo, se la, se los, se las
  • le/les + lo/la → se lo/se la

Reflexive and reciprocal

  • me levanto, te duchas, se maquilla
  • nos vemos = we see each other
  • se abrazan = they hug each other
  • pronominal: quejarse, arrepentirse

Uses of se

  • accidental: se me rompió
  • impersonal: se vive bien
  • passive: se venden casas
  • middle: la puerta se abrió

Pronoun position

  • quiero verlo / lo quiero ver
  • estoy viéndolo / lo estoy viendo
  • dámelo / no me lo des
  • siéntate / no te sientes
