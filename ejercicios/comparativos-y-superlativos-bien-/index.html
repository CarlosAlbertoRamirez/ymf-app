Practice Spanish comparatives and superlatives.

This activity helps students compare people, places, things, and ideas in Spanish. It includes tan, tanto/tanta/tantos/tantas, and intensified adjectives with -ísimo.

Comparatives

  • más + adjective + que = more / -er than
  • menos + adjective + que = less ... than
  • tan + adjective + como = as ... as
  • mejor / peor = better / worse
  • mayor / menor = older / younger

Tanto / Tanta / Tantos / Tantas

  • tanto tiempo como = as much time as
  • tanta paciencia como = as much patience as
  • tantos libros como = as many books as
  • tantas preguntas como = as many questions as
  • verbo + tanto como = trabaja tanto como

Superlatives

  • el más alto = the tallest
  • la más rápida = the fastest
  • los más interesantes = the most interesting
  • la mejor = the best
  • la peor = the worst

-ísimo / -ísima

  • buenísimo = very good / really good
  • grandísima = very big
  • dificilísimos = very difficult
  • interesantísimas = very interesting
  • The ending agrees in gender and number.
