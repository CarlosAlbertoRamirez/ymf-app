Ser vs Estar B2 Clear

B2 practice with clearer, less ambiguous examples: perfect tenses, preterite vs imperfect, affirmative and negative commands, four subjunctive levels and the three conditional patterns.

B2 · Ser vs Estar Advanced

Master ser and estar in advanced grammar contexts.

This version keeps the advanced grammar, but uses clearer contexts and fewer ambiguous cases.

Advanced meanings

  • ser listo = smart / estar listo = ready
  • ser rico = wealthy / estar rico = tasty
  • ser verde = green / estar verde = unripe
  • ser aburrido = boring / estar aburrido = bored

Past contrast

  • era = description/background
  • fue = completed event/evaluation
  • estaba = state/location background
  • estuvo = completed state/duration

Subjunctive levels

  • present: sea / esté
  • imperfect: fuera / estuviera
  • present perfect: haya sido / haya estado
  • pluperfect: hubiera sido / hubiera estado

Conditionals & commands

  • Si estudias, estarás listo.
  • Si estudiaras, estarías listo.
  • Si hubieras estudiado, habrías estado listo.
  • Sé paciente / No seas injusto.
