A2-B1 · Irregular Verbs Practice

Practice high-frequency irregular verbs in Spanish.

This version mixes multiple choice, typing, corrections, theory and challenge questions. The correct answer is checked by value, not by position.

Present irregulars

  • ser → soy, eres, es
  • estar → estoy, estás, está
  • tener → tengo, tienes, tiene
  • ir → voy, vas, va

Preterite irregulars

  • tener → tuve, tuviste, tuvo
  • hacer → hice, hiciste, hizo
  • decir → dije, dijiste, dijo
  • venir → vine, viniste, vino

Future irregulars

  • tener → tendré
  • hacer → haré
  • venir → vendré
  • decir → diré

Typing practice

  • Type the full answer.
  • Accents are accepted but not required.
  • Use the clue and time marker.
  • Press Enter to check.
